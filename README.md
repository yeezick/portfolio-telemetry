# portfolio-telemetry

Generated telemetry for erickmanrique.com/systems. One `<project>.json` per project,
emitted by the CoBrain monitor module at each project's wrap, plus an append-only
`<project>.events.ndjson`.

Nothing here is a source of truth and nothing here is executed. Every file is
machine-written, schema-validated, and passes a redaction gate before it is written.
Do not edit by hand — the next emit overwrites it.
